# React Book Store

A platform for selling books with a wide variety of titles; this is a dummy project I created while learning how to manage state in React. Built with a clean UI and responsive design, it features a dynamic book catalog.

## Tech Stack

- **Framework:** React 19 (Vite)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **State Management:** Zustand
- **API:** Google Books API
- **Routing:** React Router 7
- **UI Libraries:** Lucide React, Swiper, Sonner
- **Theming:** Next Themes (Dark/Light mode)

## 📁 Folder Structure

```text
src/
├── components/         # Organized UI blocks (home, shop, blog, contact)
├── constant/           # Mock data and navigation configs
├── hooks/              # Custom React hooks
├── lib/                # Shared utilities (cn, etc.)
├── pages/              # Main route components
├── provider/           # Global context providers (Theme)
├── store/              # Zustand global state management
└── types/              # TypeScript definitions
```
